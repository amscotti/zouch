# ADR 0001 — Zig, pinned to 0.17.x

**Status:** accepted · 2026-10-31

## Context

The project is a learning exercise in storage engines, not a product to be sold. Zig gives explicit
allocators, `defer`/`errdefer`, `comptime` layout control and C interop without a runtime. It is
pre-1.0: 0.17 removed `std.net`, `std.posix.socket`, `std.time.Timer`, `@cImport`, and
`std.Thread.Mutex`.

## Decision

Use Zig 0.17.x, pinned in `build.zig.zon`, Linux x86_64 only for v1. Keep the standard-library
surface small and route platform I/O through `std.Io`. Compile C dependencies (quickjs-ng, ICU)
with `zig cc` and hand-written `extern` declarations.

## Consequences

Upgrades are deliberate one-step migrations, not automatic. The simulator can own the clock and
disk through `std.Io`. A future port is possible because the storage engine does not depend on the
HTTP layer.
