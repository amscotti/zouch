# ADR 0006 — httpz for HTTP/1.1, Caddy for TLS and HTTP/2

**Status:** accepted · 2026-10-31

## Context

`std.http.Server` in Zig 0.17 is toolchain-grade, there is no server-side TLS in `std.crypto.tls`,
and no HTTP/2. CouchDB's own replicator is HTTP/1.1.

## Decision

Use `httpz` (HTTP/1.1, keep-alive) as the adapter, pinned by vendored source in `deps/httpz`. Put
Caddy or nginx in front for TLS and HTTP/2/3 when exposed beyond loopback. Long-lived `_changes`
feeds must not run on the request worker pool.

## Consequences

The compatibility surface is HTTP/1.1. HTTP/2 is a deployment concern, not a server concern. The
httpz version is upgraded deliberately; its test suite is run as part of upgrades.
